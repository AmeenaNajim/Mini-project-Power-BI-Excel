# Mini-project-Power-BI-Excel
🛍️ Retail Store Sales Analysis

📊 Project Overview

A retail sales analysis project using Microsoft Excel and Power BI to clean, analyze, and visualize retail transaction data.

The project focuses on sales, product, customer, category, and location performance and provides actionable business insights.

🛠️ Tools Used

- Excel – Data cleaning and preprocessing
- Power BI – Dashboard and visualization
- DAX – Measures and calculations

🧹 Data Cleaning

The dataset was cleaned in Excel by:

- Handling missing values
- Removing duplicates
- Standardizing inconsistent data
- Correcting data types and formats
- Creating Month-Year for time analysis

📈 Dashboard

The Power BI dashboard contains 4 pages:

- Executive Dashboard – Overall sales performance
- Product Analysis – Product and category performance
- Customer Analysis – Customer purchasing patterns
- Insights & Recommendations – Key findings and business recommendations

A separate Drill-through page provides detailed customer transactions.

🔍 Power BI Features

- KPI Cards
- Slicers
- Buttons & Page Navigation
- Bookmarks
- Drill-through
- DAX Measures
- Interactive Visualizations

💡 Key Insights

- Online customers contributed the highest sales.
- Food and Furniture showed strong sales volumes.
- Patisserie showed relatively lower volume at a similar price point.
- Electric Household Essentials performed well at higher price points.
- Higher-priced categories showed comparatively lower sales volume.
- Sales showed a declining trend over the analyzed period.

🚀 Project Workflow

Raw Data → Excel Cleaning → Power BI Analysis → Dashboard → Insights & Recommendations
